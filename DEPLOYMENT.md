# Развёртывание SHYMKENT STUDIO

Полное руководство по развёртыванию веб-сайта подкаст-студии.

## 📋 Предварительные требования

- Node.js 18+ установлен
- npm или yarn
- Учётная запись Vercel (для развёртывания)
- Домен (можно купить на Porkbun)
- Данные для Kaspi Payment (если используется)

## 🚀 Этап 1: Локальная разработка

### Установка и запуск

```bash
# Установить зависимости
npm install

# Создать .env.local на основе .env.example
cp .env.example .env.local

# Заполнить переменные окружения
nano .env.local
```

### Запуск dev сервера

```bash
npm run dev
```

Сайт будет доступен на http://localhost:3000

### Сборка для производства

```bash
npm run build
npm start
```

## 🌐 Этап 2: Развёртывание на Vercel

### Вариант А: Через CLI

```bash
# Установить Vercel CLI
npm i -g vercel

# Авторизоваться
vercel login

# Развернуть
vercel
```

### Вариант Б: Через веб-интерфейс

1. Перейти на https://vercel.com
2. Нажать "New Project"
3. Выбрать репозиторий GitHub (если используется)
4. Или подключить проект вручную
5. Настроить переменные окружения
6. Развернуть

### Переменные окружения на Vercel

Установить в Project Settings → Environment Variables:

```
NEXT_PUBLIC_KASPI_MERCHANT_ID=<your_merchant_id>
KASPI_SECRET_KEY=<your_secret_key>
NEXT_PUBLIC_PHONE=+7 700 503 05 01
NEXT_PUBLIC_WHATSAPP=+7 700 503 05 01
NEXT_PUBLIC_EMAIL=salem@shymkent.studio
NEXT_PUBLIC_INSTAGRAM=@shymkent.studio
NEXT_PUBLIC_SITE_URL=https://shymkent.studio
NEXT_PUBLIC_OPEN_DATE=2026-11-10
NEXT_PUBLIC_ANALYTICS_DISABLED=true
```

## 🌍 Этап 3: Настройка домена

### Купить домен на Porkbun

1. Перейти на https://porkbun.com
2. Поиск домена `shymkent.studio`
3. Добавить в корзину и оплатить
4. Перейти в Account → Domains

### Подключить домен к Vercel

#### Способ 1: Через NS записи (рекомендуется)

1. На Porkbun:
   - Перейти в управление доменом
   - Найти "Nameservers"
   - Изменить на Vercel DNS:
     - `ns1.vercel-dns.com`
     - `ns2.vercel-dns.com`
     - `ns3.vercel-dns.com`
     - `ns4.vercel-dns.com`

2. На Vercel:
   - Перейти в Project Settings → Domains
   - Добавить домен `shymkent.studio`
   - Vercel автоматически создаст DNS записи

#### Способ 2: Через A записи (альтернатива)

1. На Vercel:
   - Получить IP адреса проекта

2. На Porkbun:
   - Добавить A записи, указывающие на Vercel

## 🔒 Этап 4: SSL сертификат

Vercel автоматически генерирует SSL сертификат через Let's Encrypt.
- HTTPS включается автоматически
- Сертификат обновляется автоматически

## 📧 Этап 5: Email и контакты

### Настройка Gmail для отправки писем

Если используется Gmail для отправки уведомлений:

1. Включить 2-factor authentication в Google Account
2. Создать App Password:
   - Перейти на https://myaccount.google.com/security
   - Найти "App passwords"
   - Выбрать Mail и Windows/Linux/Mac
   - Скопировать пароль
3. Использовать пароль приложения в переменных окружения

### Настройка контактных данных

Обновить контакты в переменных окружения:

```
NEXT_PUBLIC_PHONE=+7 700 503 05 01
NEXT_PUBLIC_WHATSAPP=+7 700 503 05 01
NEXT_PUBLIC_EMAIL=salem@shymkent.studio
NEXT_PUBLIC_INSTAGRAM=@shymkent.studio
```

## 💳 Этап 6: Интеграция Kaspi Payment

### Получить учётные данные Kaspi

1. Зарегистрировать бизнес на https://kaspi.kz
2. Перейти в Personal Cabinet
3. Найти раздел "Merchant Tools" или "API"
4. Получить:
   - `NEXT_PUBLIC_KASPI_MERCHANT_ID` (публичный ID)
   - `KASPI_SECRET_KEY` (приватный ключ)

### Настроить Kaspi на сайте

1. Заполнить переменные окружения
2. Создать endpoint для обработки платежей `/api/payments/kaspi`
3. Настроить webhook для подтверждения платежей

### Тестирование платежей

Kaspi предоставляет тестовую среду:
- Использовать тестовые учётные данные для разработки
- Переключиться на продакшн перед запуском
