# SHYMKENT STUDIO — Подкаст-студия Шымкента

Веб-сайт и система управления бронированиями для подкаст-студии SHYMKENT STUDIO в Шымкенте.

## Возможности

- **Информационный сайт** с описанием комнат, оборудования и услуг
- **Система бронирования** с пошаговым интерфейсом
- **Запрос на бесплатный тур** по студии
- **Интеграция Kaspi** для обработки платежей
- **Адаптивный дизайн** для всех устройств
- **Оптимизация для поиска** (SEO)

## Запуск локально

### Требования

- Node.js 18+ (рекомендуется 20+)
- npm или yarn

### Установка

```bash
# Клонировать репозиторий
git clone <repo-url>
cd shymkent-studio

# Установить зависимости
npm install

# Создать файл .env.local на основе .env.example
cp .env.example .env.local

# Запустить сервер разработки
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Интеграции

### Kaspi Payment

Интеграция с Kaspi для обработки платежей. Требуется:

- `NEXT_PUBLIC_KASPI_MERCHANT_ID` — ID мерчанта
- `KASPI_SECRET_KEY` — секретный ключ

### Google Analytics (отключен по умолчанию)

Соблюдение приватности пользователей. Установите `NEXT_PUBLIC_ANALYTICS_DISABLED=false` для включения.

## Конфигурация

Скопируйте `.env.example` в `.env.local` и заполните необходимые переменные:

```bash
cp .env.example .env.local
```

### Переменные окружения

- `DATABASE_URL` — URL базы данных для бронирований
- `NEXT_PUBLIC_KASPI_MERCHANT_ID` — ID мерчанта Kaspi
- `KASPI_SECRET_KEY` — Секретный ключ Kaspi
- `NEXT_PUBLIC_PHONE` — Номер телефона студии
- `NEXT_PUBLIC_WHATSAPP` — WhatsApp номер
- `NEXT_PUBLIC_EMAIL` — Email адрес
- `NEXT_PUBLIC_INSTAGRAM` — Instagram профиль
- `NEXT_PUBLIC_SITE_URL` — URL веб-сайта
- `NEXT_PUBLIC_OPEN_DATE` — Дата открытия (формат: YYYY-MM-DD)

### Стилизация

Проект использует **Tailwind CSS** для стилизации. Переменные цветов определены в `tailwind.config.ts`.

Для добавления новых стилей:

1. Используйте готовые Tailwind классы
2. Если нужны пользовательские стили, добавьте их в `globals.css`

## Ключевые моменты

### Дата открытия

Сайт работает в режиме «Скоро открытие» до **10 ноября 2026**. Принимаются заявки на бронирование и туры.

### Условия бронирования

- **Оплата**: 100% предоплата через Kaspi
- **Отмена**: До 24 часов — полный возврат
- **Перенос**: До 24 часов — свободен, после — только по причинам

### Правки монтажа

В пакет входит **2 правки** монтажа. Дополнительные правки оплачиваются отдельно.

### Сроки доставки

- **Исходники**: 24 часа
- **Монтаж**: 3 рабочих дня (пн-пт)
