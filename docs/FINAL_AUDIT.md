# Итоговый аудит SHYMKENT STUDIO

Дата: 25.09.2026. История этапов 1–4 — [AUDIT.md](AUDIT.md). Этот документ фиксирует финальную проверку и состояние перед production.

## 1. Найдено и исправлено

### Критичное
- **Next.js 14.2 (EOL) с критической уязвимостью** (неаутентифицированный RCE в оптимизаторе изображений, DoS серверных действий, SSRF и др.). Обновлено до Next.js 15.5.26 + React 19: переход на асинхронные `cookies()`/`headers()`/`params`, `useActionState`, `serverExternalPackages`. `npm audit`: 0 уязвимостей (для вложенных postcss и deepmerge-ts добавлены `overrides`).
- **Открытый прокси изображений:** `images.remotePatterns: '**'` позволял оптимизатору загружать любые внешние картинки. Теперь только локальные файлы.
- **Формы CRM «зависали»** после сохранения с `revalidatePath` из-за сочетания `loading.tsx` и перерисовки в транзакции (найдено E2E-тестом). Скелетон удалён, формы работают.
- **React 19 сбрасывал форму при ошибке валидации** (терялся ввод). Сделан `useKeepAction`: при ошибке ввод сохраняется, формы создания очищаются после успеха.

### Бизнес-логика
- Задачи production по отменённым и «не пришёл» заказам оставались на доске и считались просроченными. Теперь они заморожены: скрыты с доски и дашборда, изменить их нельзя, история сохраняется. При возврате заказа в «Подтверждён» задачи возвращаются.
- Напоминания по отменённым и перенесённым заказам и турам висели в очереди как «ожидают отправки». Теперь снимаются («не отправлено (отмена/перенос)»).
- У отменённого заказа показывался красный «Остаток 20 000 ₸». Теперь «—».
- Сообщения об успехе пропадали: закрывался блок оплаты, исчезала строка задачи после «Повторить». Исправлено (панель остаётся открытой, результат повтора — баннером на странице).
- Журнал платежей (все клиенты и суммы) был виден оператору и монтажёру. Теперь только ролям, работающим с деньгами. Статус оплаты в заказах и задачах им по-прежнему виден.
- На дашборд добавлено «Завершено съёмок за период».

### Сайт
- Контакты, политика, условия, цены и комнаты были только на русском (при выборе казахского язык смешивался). Теперь все страницы на RU и KK, `lang` у `<html>` меняется вместе с языком.
- На «Контактах» стоял фиктивный блок «Карта / Интерактивная карта» и захардкоженные адрес и дата открытия. Теперь адрес (RU/KK), ссылка на карту, название студии и дата открытия берутся из CRM → «Настройки». Объявление об открытии показывается только до этой даты. Добавлено время работы из расписания.
- В условиях были устаревшие названия тарифов («Запись без монтажа», «Полный подкаст») и срок «3 рабочих дня» (в FAQ — 3–5). Условия и политика переписаны под фактическую работу системы (какие данные собираются, где хранятся, кому передаются, правила отмены из настроек, Kaspi только по ссылке).
- FAQ: дублировался первый вопрос; цены, длительности и вместимость были вписаны в текст. Теперь они подставляются из каталога CRM.
- «/rooms»: мраморный стол ошибочно был приписан маленькой комнате (по фото он в Living Room). Вместимость и цены берутся из каталога. Неизвестная комната отдаёт настоящий 404 (раньше был редирект).
- Абонементы: кнопки «Выбрать» вели на форму разовой записи, где абонемент оформить нельзя. Теперь «Обсудить в WhatsApp» и пометка «оформляются через администратора».
- Казахский перевод: исправлены ошибки, меняющие смысл («құнсыз» = «бесполезный» вместо «тегін»; «қосымша төлемсіз» = «без доплаты» вместо «за доплату»; русское «один» внутри казахского текста; «Қосымша бөлме» вместо Living Room; «кішкентай қоршағын»), удалено 38 неиспользуемых ключей. Тест проверяет совпадение ключей и плейсхолдеров RU/KK.
- Производительность: YouTube загружается только по нажатию (превью, `youtube-nocookie`); фоновое видео 12,5 МБ не грузится на телефонах, при reduced motion и Data Saver; шрифт Onest раздаётся с сайта через `next/font` (без запросов к Google, с казахскими буквами).
- Доступность: ссылка «перейти к содержанию», видимый фокус, `aria-expanded`/`aria-controls` в меню и FAQ, `aria-pressed` у переключателя языка, закрытие меню по Esc и при переходе, кнопки слайдера видны с клавиатуры и на тач-устройствах, цели касания ≥ 44 px. Контраст: оранжевый для текста на светлом фоне затемнён до `#C84A12` (4,7:1, было 2,85:1); яркий `#FF6B24` остался для тёмного фона.
- Добавлены страница 404 в стиле сайта, страницы ошибок (сайт, CRM, глобальная), favicon (знак из логотипа), Open Graph-изображение (кадр Living Room).

### Эксплуатация и безопасность
- Строгая проверка переменных окружения при старте (`instrumentation.ts`, `lib/env-schema.ts`, `npm run env:check`).
- `/api/health` (жив) и `/api/ready` (база, миграции, конфигурация) — без версий и деталей.
- Структурированные JSON-логи с `X-Request-Id` и вычисткой персональных данных.
- IP для лимитов берётся с учётом `TRUSTED_PROXY_COUNT`: подделка `X-Forwarded-For` клиентом не проходит.
- `CRON_SECRET` не короче 32 символов.
- CSP ужесточена (без Google Fonts, картинки — только свои и превью YouTube). Добавлены CORP, `X-DNS-Prefetch-Control`; устаревший `interest-cohort` заменён.
- Отправка из очереди после ответа через `after()` — надёжно и на Vercel.
- Воркер очереди корректно завершается по SIGTERM и раз в час чистит старые данные.
- Подтверждение опасных действий: отмена заказа, возврат, сторно, объединение клиентов, удаление из каталога.
- Состояние системы в CRM → «Интеграции»: база, миграции, конфигурация, «очередь стоит > 10 минут», последняя успешная отправка.
- Скрипты `db:backup`, `db:restore-check`, `db:drift`; `Dockerfile`, `.dockerignore`, `vercel.json` (cron).
- Устаревшие инструкции (`BOOKING_SETUP.md`, `.env.local.example`, корневой `DEPLOYMENT.md`) заменены ссылками на актуальные документы.

## 3. SEO

- Уникальные title и description, canonical, `metadataBase`, Open Graph (изображение 1200×630), favicon, sitemap (11 публичных страниц, без `/admin` и `/api`), robots (закрыты `/admin`, `/api`), JSON-LD `ProfessionalService`/`LocalBusiness` только из реальных данных (контакты и часы из настроек, цены из каталога; без рейтингов и отзывов).
- `/admin` — `noindex, nofollow` (мета-тег и заголовок), `no-store`.
- **hreflang не используется намеренно.** Язык переключается на клиенте, отдельных URL для казахской версии нет, сервер отдаёт русскую. Ложный hreflang на тот же URL — неверный сигнал. Для индексации казахской версии нужны отдельные маршруты (`/kk/...`), это отдельная задача.

## 4. Ограничения, которые нельзя устранить без внешнего доступа

- Реальная отправка писем, события Google Calendar и строки Google Sheets проверены только в dry-run: нет production-учётных данных SMTP, Google и Apps Script.
- Автоматической оплаты Kaspi нет: нужен договор и официальный API. Реализованы ручные ссылки и подтверждение (сайт честно об этом пишет).
- Docker-образ не собирался: на машине нет Docker. Проверен тот же путь запуска: standalone-сборка, `node server.js`, бандл воркера `scripts-dist/outbox-worker.js`.
- Выкладка, домен, HTTPS/HSTS в боевых условиях, Vercel Cron — требуют аккаунтов хостинга и DNS.
- Юридические тексты не являются юридической консультацией и требуют проверки юристом в Казахстане.
- Казахский перевод не вычитан носителем языка — требуется финальная вычитка.
