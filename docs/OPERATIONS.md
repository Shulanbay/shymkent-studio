# Ежедневная работа студии в CRM

CRM: `https://shymkent.studio/admin`. Время везде — Шымкент (Asia/Almaty). Простая пошаговая версия для владельца — [OWNER_HANDOFF.md](OWNER_HANDOFF.md).

## Роли

| Роль | Что может |
|---|---|
| Владелец (OWNER) | всё: сотрудники, интеграции (Google), настройки, платежи и возвраты |
| Администратор (ADMIN) | всё операционное: заказы, лиды, клиенты, туры, каталог и настройки, платежи и возвраты; не управляет сотрудниками и подключением Google |
| Менеджер (MANAGER) | лиды, клиенты, заказы, туры, регистрация оплат и ссылок на оплату, production-задачи; без возвратов, сторно и системных настроек |
| Оператор (OPERATOR) | просмотр заказов и календаря, туры, свои задачи подготовки и записи, статус оплаты (без журнала платежей) |
| Монтажёр (EDITOR) | свои задачи монтажа, shorts, обложки, проверки и передачи; статус оплаты заказа в карточке задачи |

Права проверяются на сервере: скрытая кнопка не даёт доступа, а прямой запрос к запрещённому действию отклоняется.

## Жизненный цикл заказа

```
Новая заявка → Связались → Ждёт оплаты → Подтверждён → Завершён
                                    ↘ Отменён (с причиной и расчётом возврата)
                     Подтверждён → Не пришёл
```

1. **Новая заявка** приходит с сайта. Клиент создаётся или находится по телефону (дублей нет). Администратор получает письмо, клиент — «заявка получена» (если указал email).
2. **Связаться** с клиентом (телефон или WhatsApp), уточнить детали → статус «Связались».
3. **Ссылка на оплату:** создать счёт в Kaspi Pay, вставить в «Ссылка на оплату (Kaspi)» → статус «Ждёт оплаты».
4. **Оплата пришла:** «Добавить оплату» → сумма, способ, номер чека → «Провести». Частичная оплата допустима; статус оплаты считается автоматически.
5. **Подтвердить** → создаются production-задачи по шаблону тарифа, лид переходит в «Успешно», клиенту уходит «бронь подтверждена», планируются напоминания за 24 и 2 часа, событие появляется в Google Calendar.
6. После съёмки → «Завершён». Монтаж ведётся на доске Production. Когда задача «Передача» закрыта со ссылкой на материалы, клиенту уходит «заказ готов».

## Перенос и отмена

- **Перенос:** карточка заказа → «Перенос» → дата → «Показать слоты» → время → «Перенести». Показываются только свободные слоты этой комнаты с учётом буферов. CRM подсказывает, бесплатный ли перенос по правилам. Сроки задач сдвигаются, клиенту уходит письмо, событие в календаре обновляется.
- **Отмена:** «Отмена» → причина → «Отменить заказ». Время освобождается сразу. CRM показывает сумму возврата по правилам. Другую сумму может указать только владелец или администратор (с причиной). Задачи заказа снимаются с доски, напоминания отменяются.
- **Возврат денег** — отдельная операция: «Возврат клиенту» → сумма (не больше оплаченного) → причина → «Провести возврат».

## Деньги

- Все суммы — целые тенге. Проведённые операции не редактируются и не удаляются.
- Ошибочная операция исправляется **сторно** (компенсирующая запись; только владелец и администратор).
- Наличные — только ручной способ в CRM; на сайте их нет.
- Раздел «Платежи»: журнал операций и вкладка «Задолженности» (активные заказы с остатком).
- Выручка на «Обзоре» = поступления − возвраты ± сторно, по дате движения денег.

## Лиды

- Создаются автоматически из заявки на тур (и из записи, если включено в «Настройках»). Вручную — «Лиды» → «Создать лид».
- Этапы: Новый → Связались → Тур назначен → Предложение отправлено → Успешно / Отказ (отказ — с причиной).
- Доска (канбан) поддерживает перетаскивание; следующий контакт и ответственный задаются в карточке лида.

## Туры

- Туры не блокируют комнаты. Друг с другом они не пересекаются: один ведущий.
- «Туры» → карточка → «Подтвердить» (клиенту уходит письмо и планируется напоминание), перенос, отмена, заметки.

## Production

- Доска: К выполнению → В работе → Проверка → Готово. Фильтры по исполнителю, этапу, сроку и заказу. Просроченные задачи отмечены красным.
- Исполнителя, срок и приоритет назначает менеджер. Оператор и монтажёр меняют только свои задачи своего этапа: статус, чек-лист, комментарии, ссылка на материалы.
- Шаблоны задач по тарифам: «Настройки» → «Каталог» → «Шаблоны задач». Изменения применяются к новым подтверждениям.

## Настройки (владелец / администратор)

| Раздел | Что меняется |
|---|---|
| Правила отмены и переноса | пороги полного и частичного возврата, число бесплатных переносов. Тексты на сайте, в FAQ и письмах обновятся сами |
| Рабочее время | часы по дням, шаг слотов, минимальное время до записи, горизонт записи, длительность тура. **Исключения:** `2026-12-31 выходной` или `2026-12-30 10:00-16:00` |
| Каталог | комнаты (вместимость, буферы, цвет), тарифы (цена, длительность, шаг продления). Использованные нельзя удалить — только архив |
| Контакты студии | название, телефон, WhatsApp, email, Instagram, адрес RU/KK, ссылка на карту, дата открытия |
| Напоминания и лиды | напоминания 24 ч / 2 ч, за сколько часов напоминать о туре, автолид из заявки |
| Интеграции (владелец) | вкл/выкл почты, Calendar, Sheets; подключение Google Calendar |

## Регламент

**Каждый день:** «Обзор» (новые заявки, съёмки сегодня, задолженности, просроченные задачи, ошибки интеграций) → обработать новые заявки → проверить календарь на завтра.

**Каждую неделю:** «Интеграции» → нет ли FAILED; «Платежи» → «Задолженности»; лиды без следующего контакта.

**Каждый месяц:** проверить, что резервные копии создаются, и один раз запустить `npm run db:restore-check` ([BACKUP_RESTORE.md](BACKUP_RESTORE.md)); отключить уволенных сотрудников («Сотрудники» → снять «Активен»).
